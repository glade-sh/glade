# CLI reference

This page is a stable reference entry point. Use the linked detailed page or generated artifact when you need the full table.

Use this page when you need the command shelf, not a walkthrough.
The full guide carries examples, flags, and current command groups.

## Start here

Start with the command you plan to run.
Most project commands accept `--project <root>`.
When Glade can discover the project, the current directory is enough.

Use `glade help commands` at the terminal for the live binary.
Use the full CLI list when you need hosted docs.
Use JSON and exit-code docs when wiring automation.
