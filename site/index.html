LOCAL APEX RUNTIME / ORG: NONE

Run Apex without the org round trip.

Glade parses, type-checks, and executes Salesforce Apex on your machine. Tests, SOQL, DML, triggers, limits, editor tools, CI reports, and a local Salesforce-shaped API all run from one Go binary.

INNER LOOP

The short path through Apex work.

The command line is the front panel. Each command uses the same parser, checker, VM, storage, and compatibility fixtures.

Check source

Build local diagnostics before deploy time.

$ glade check --project . --json

Run tests

Execute supported Apex tests with isolated local data.

$ glade test --project . --json

Try anonymous Apex

Use the runtime directly for small probes.

$ glade exec 'System.debug(1+1);'

Run a local API

Exercise Salesforce-shaped REST flows against local state.

$ glade server --db local.sqlite
