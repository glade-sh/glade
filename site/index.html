The same runtime everywhere.

01

Parse and index. Apex files, triggers, schema metadata, and project layout become a local symbol graph.

02

Check and lower. Diagnostics are shaped for machines, then supported code lowers into executable IR.

03

Execute locally. The VM routes SObjects, SOQL, DML, triggers, limits, storage, and common platform APIs.
