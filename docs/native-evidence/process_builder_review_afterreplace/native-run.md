# Native run

A fresh 30-day Developer scratch org with Person Accounts used synthetic metadata. The synthetic project was deployed at API 67.0 and the field permission set assigned. Two separate active synthetic users were created without sending user email; the second used an available platform license. A changed user lookup drives a prior-share deletion followed by an automatically stored share creation. Named and anonymous executions at API 62.0 and 67.0 captured successful replacement, missing-share rejection, and mixed partial-save controls in both input orders. Sentinel assertions carry observations and roll back the transactions. The replay provides equivalent synthetic users in test setup. ScratchOrgInfo was verified Deleted and no ActiveScratchOrg record remained. IDs and aliases are not recorded.
