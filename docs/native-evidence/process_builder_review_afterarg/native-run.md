# Native run

A fresh 30-day Developer scratch org with PersonAccounts enabled was used with the synthetic project from process_builder_review_afterperson overlaid with this fixture project. Source metadata was deployed at API 67.0 and the synthetic field permission set assigned. A second synthetic user was created with user-email options disabled. Named and anonymous executions ran at API 62.0 and 67.0. The rows use a second Apex invocable input parameter name and cover insert actions, share creation and deletion, related update, missing-share rejection and nonmatch controls. Named tests cannot send email; anonymous executions deliberately raise an uncaught sentinel assertion after writing the marker, so their transactions roll back before post-commit email. ScratchOrgInfo was verified Deleted and no ActiveScratchOrg record remained. IDs and aliases are not recorded.
