# Native capture: clearing required lookup fields

A fresh 30-day Developer scratch org was created from a campaign Dev Hub. At API 62 and 67 independent synthetic tests attempted two populated records per object, then cleared the first lookup in system mode and re-queried only after success. AuthorizationFormConsent.AuthorizationFormTextId, CaseTeamTemplateMember.TeamRoleId, ContentWorkspaceMember.ContentWorkspacePermissionId, DuplicateRecordSet.DuplicateRuleId, Order.AccountId and TimeSheet.ServiceResourceId rejected the clear. OpportunityLineItem.PricebookEntryId and ServiceAppointment.ParentRecordId described as non-updateable. ContractLineOutcome.RecordsetFilterCriteriaId and MobileSettingsAssignment.ProfileId failed to create both setup records. No ordering result was inferred. All tests rolled back; the scratch org was deleted and ScratchOrgInfo status verified as Deleted.
