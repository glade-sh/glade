# Native capture: MessagingSession conversation setup boundary

A fresh 30-day Developer scratch org with LiveAgent and LiveMessage was created from a campaign Dev Hub. At API 62 and 67 a synthetic test created a MessagingSession, then found its ConversationId null and the Conversation count zero. The same test repeated the WorkPlan WorkOrder ordering matrix. No message was sent; test records rolled back. This is setup evidence, not an ordering result for the Conversation lookups. The scratch org was deleted and ScratchOrgInfo status verified as Deleted.
