# Native run

A fresh 30-day Developer scratch org was used with synthetic metadata. Source metadata was deployed at API 67.0 and the synthetic field permission set assigned. Named and anonymous executions ran at API 62.0 and 67.0. The rows cover a three-flow Case graph with a queue lookup and triggering-record update, an Apex action, and an Apex action behind two decisions, custom errors, and a Case lookup. Matching and nonmatching conditions, a changed-field control, and two custom-error rejection controls are recorded. The synthetic actions do not send messages. Named tests and anonymous executions deliberately raise a sentinel assertion after producing the result, rolling back their transactions. ScratchOrgInfo was verified Deleted and no ActiveScratchOrg record remained. IDs and aliases are not recorded.
