# Native capture: Flow action fault indices

A fresh 30-day scratch org was created from a campaign Dev Hub. Only the synthetic metadata in `project/` was deployed. The synthetic permission set was assigned in the test; test insert statements explicitly use system mode. The source files in `project/` have Flow and action API 62; `ceiling-flow.xml` and `ceiling-action-meta.xml` are the exact API 67 variants. The API 67 Flow/action was deployed first and test classes at 62 and 67 were run, then Flow/action were redeployed at API 62 and the API 62 test rerun. Observations are the JSON assertion payloads, with identifiers, email addresses and URLs scrubbed. The clean input is the acceptance control. The scratch org was deleted and its ScratchOrgInfo status verified as Deleted.
