# Standard price control

Captured 2026-11-23 in a fresh 30-day Developer scratch org, then deleted and verified gone. At Apex API 62.0 and 67.0 an isolated test creates a standard price for one product. A custom price for that product succeeds; a custom price for a second product without a standard price returns STANDARD_PRICE_NOT_DEFINED. The standard price itself succeeds. Other currencies and inactive prices were not captured.
