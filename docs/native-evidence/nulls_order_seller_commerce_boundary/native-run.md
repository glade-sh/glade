# Native capture: seller account alternate under commerce profile

A fresh 30-day Developer scratch org with B2BCommerce, PersonAccounts and Communities was created from a campaign Dev Hub. At API 62 and 67 synthetic tests created Individual parents, then the proposed Seller.AccountId alternate failed with Invalid field AccountId for Seller. No commerce site was created and no ordering result was inferred. Tests rolled back and the scratch org was deleted, with ScratchOrgInfo status verified as Deleted. Earlier creation attempts missing the required Communities feature created no scratch org.
