# Native run

A fresh 30-day Developer scratch org deployed synthetic metadata from two package directories. A literal directory rule in .forceignore excluded the first customMetadata directory containing the true record; a false record in the other package was included. A direct Salesforce query found no true record and one false record. Named and anonymous executions at API 62.0 and 67.0 captured the ignored-record after-insert failure, the included false-record success, and an absent-name failure. The trigger itself was deployed at the corresponding API version for each run. Sentinel assertions carry observations and roll back transactions. The org was deleted and ScratchOrgInfo verified Deleted; no matching ActiveScratchOrg row remained. Org IDs and aliases are not recorded.
