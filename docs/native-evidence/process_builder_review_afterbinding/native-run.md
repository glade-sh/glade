# Native run

A fresh 30-day Developer scratch org deployed synthetic metadata. A process supplied the related record ID through the same custom relationship used in the first lookup filter. The subflow projected the ID and long-text source field on its second lookup. Named and anonymous executions at API 62.0 and 67.0 recorded matching records, a null-lookup boundary, and a rejected nested update. Sentinel assertions carry the observations and roll back transactions. The org was deleted and its ScratchOrgInfo status verified Deleted; no matching ActiveScratchOrg row remained. Org IDs and aliases are not recorded.
