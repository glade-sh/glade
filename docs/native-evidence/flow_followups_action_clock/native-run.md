# Native capture: Flow action date and null output

A fresh 30-day scratch org was created from a campaign Dev Hub and only the synthetic project deployed. The project has API 62 Flow and action metadata; the ceiling files are the exact API 67 versions. API 67 Flow/action was deployed first and tests at 62 and 67 were run, then both were redeployed at API 62 and the 62 test rerun. The synthetic test sets the current test user's time zone to America/Los_Angeles, verifies it, and inserts with system mode. The normal input is 02:15 GMT and the target Date and Datetime fields are prepopulated. Three null-output shapes and an overlength rejection are included. Observations are JSON assertion payloads with identifiers, email addresses and URLs scrubbed. The scratch org was deleted and its ScratchOrgInfo status verified as Deleted.
