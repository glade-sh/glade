# Native capture: Flow record-create formula variable precedence

A fresh 30-day scratch org was created from a campaign Dev Hub and the synthetic project deployed. The project contains API 62 Flow sources and test classes pinned at 62 and 67. The ceiling files contain the exact API 67 Flow sources. The 67 sources were deployed first and both test classes run; both flows were then redeployed at 62 and the 62 class rerun. The test inserts a defaulted-variable case, an unset-variable case and a nonmatching control with system-mode DML. After-save Flows create synthetic child records with the formula result. An overlength field is the rejection control. Observations are JSON assertion payloads with identifiers, email addresses and URLs scrubbed. The scratch org was deleted and its ScratchOrgInfo status verified as Deleted.
