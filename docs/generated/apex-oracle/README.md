# Apex Oracle Generated Artifacts

This directory is generated by `glade compat oracle`.

Files:
- `INVENTORY.json`: Unified surface inventory.
- `DOMAINS.json`: Parameter domain values used by probe planning.
- `PROBE_MANIFEST.json`: Lab evidence specs for the selected packet area and limit.
- `WORK_QUEUE.json`: Sharded lab queue used by generator and runners.
- `COVERAGE.json`: Coverage summary derived from inventory statuses.

`PROBE_MANIFEST*.json` and `WORK_QUEUE*.json` answer packet evidence questions.
They are not the broad Salesforce implementation backlog.

Regenerate from a surface packet:

```bash
tmp="$(mktemp -d)"
go run ./cmd/glade compat surface refresh \
  --docs "$GLADE_SALESFORCE_DOCS_SOURCE" \
  --tooling-completions testdata/generated/tooling_system_symbols.json.gz \
  --out "$tmp"
go run ./cmd/glade compat oracle inventory \
  --ledger "$tmp/SURFACE_LEDGER.json" \
  --gap-class missing-evidence \
  --limit 25 \
  --output docs/generated/apex-oracle/INVENTORY.json
go run ./cmd/glade compat oracle domains --output docs/generated/apex-oracle/DOMAINS.json
go run ./cmd/glade compat oracle plan --inventory docs/generated/apex-oracle/INVENTORY.json --domains docs/generated/apex-oracle/DOMAINS.json --manifest docs/generated/apex-oracle/PROBE_MANIFEST.json --work-queue docs/generated/apex-oracle/WORK_QUEUE.json --area stdlib.core --limit 200 --shard-count 8
go run ./cmd/glade compat oracle report --inventory docs/generated/apex-oracle/INVENTORY.json --output docs/generated/apex-oracle/COVERAGE.json
```

The old stub-root inventory path is legacy. Use it only to inspect old stub
artifacts, not to choose broad Salesforce work:

```bash
go run ./cmd/glade compat oracle inventory --stubs <stub-root> --output /tmp/legacy-oracle-inventory.json
```
