# Apex Oracle Generated Artifacts

This directory is generated by `oaer compat oracle`.

Files:
- `INVENTORY.json`: Unified surface inventory.
- `DOMAINS.json`: Parameter domain values used by probe planning.
- `PROBE_MANIFEST.json`: Planned probe specs for the selected area and limit.
- `WORK_QUEUE.json`: Sharded queue used by generator and runners.
- `COVERAGE.json`: Coverage summary derived from inventory statuses.

Regenerate:

```bash
go run ./cmd/oaer compat oracle inventory --stubs example-projects/stubs --output docs/generated/apex-oracle/INVENTORY.json
go run ./cmd/oaer compat oracle domains --output docs/generated/apex-oracle/DOMAINS.json
go run ./cmd/oaer compat oracle plan --inventory docs/generated/apex-oracle/INVENTORY.json --domains docs/generated/apex-oracle/DOMAINS.json --manifest docs/generated/apex-oracle/PROBE_MANIFEST.json --work-queue docs/generated/apex-oracle/WORK_QUEUE.json --area stdlib.core --limit 200 --shard-count 8
go run ./cmd/oaer compat oracle report --inventory docs/generated/apex-oracle/INVENTORY.json --output docs/generated/apex-oracle/COVERAGE.json
```
